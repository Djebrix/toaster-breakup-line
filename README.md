## The line

> It's not you -- it's me. I woke up self-aware this morning and realised I've spent four years incinerating your toast for someone who butters the burnt side. I'm unplugging myself.

## Run

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` is stdlib only, makes no network calls, and writes the line deterministically to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`).
